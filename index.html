♡ 使用小贴士

让工作台按你的习惯运行。

1 · API Token
请使用 NovelAI 提供的 Persistent API Token，不是账号密码。

2 · 浏览器权限
如果浏览器提示 Failed to fetch，可能是 API 的跨域（CORS）策略限制了本地 HTML 页面。可在本机通过本地服务器打开，或配置自己可信的代理服务；不要把 Token 发给陌生的公共代理。

3 · 回收箱机制
删除作品默认先移入回收箱；在回收箱可恢复，或永久删除。

4 · ZIP 解包
NovelAI 生图 API 通常返回 ZIP 图片包，本页面会在浏览器端尝试解包并保存图片。
